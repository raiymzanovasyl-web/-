# Управляющая программа лазерной резки: панель забора «Ёлочка» 2400×1500

Размеры взяты с чертежа: панель 2400×1500 мм, лист 2–3 мм, 320 секций на 800 м (шаг 2,5 м).

| Файл | Назначение |
|---|---|
| `output/panel_2400x1500.nc` | G-code для станка (керф уже учтён, подводы, порядок резки) |
| `output/panel_2400x1500.dxf` | Номинальная геометрия (слои `CUT_INNER`, `CUT_OUTER`) для CypCut / FSCUT и др. |
| `output/panel_2400x1500.svg` | Превью |
| `generate_panel.py` | Генератор: меняете параметры, запускаете `python3 generate_panel.py` |

## Рисунок
Рамка 50 мм, 4 «ёлочки» (ствол 30 мм, перемычки между ними 30 мм),
диагональные ламели 30 мм под 45°, прорези 45 мм. 128 отверстий, ~49 % просвета.

## Программа
* `G21 G90`, ноль — левый нижний угол листа, заготовка от 2420×1520 мм.
* Сначала все внутренние отверстия (по ближайшему соседу), наружный контур — последним.
* Прожиг внутри отхода, подвод 5 мм, пауза на прожиг `G4`.
* Компенсация ширины реза 0,2 мм (kerf/2) уже в координатах — G41/G42 не включать.
* Лазер: `M3 S…` / `M5` (для своей стойки поменяйте `LASER_ON`/`LASER_OFF`, например `M07`/`M08`).

Режимы по умолчанию (сталь 3 мм, волокно 1–2 кВт): F3200 мм/мин, прожиг 0,6 с, керф 0,25 мм; для 2 мм — `THICKNESS = 2.0` (F4500).
Длина реза ≈ 102 м, ≈ 35 мин на панель (лист 3 мм). Перед запуском проверьте режимы по таблице своего источника.

## Раскрой: приложение в браузере
`app/index.html` — откройте файл в браузере, ничего ставить не нужно.
Меняете размеры рисунка, толщину листа и цены, а приложение сразу пересчитывает
отверстия, просвет, длину реза, время, массу, отход и стоимость партии,
показывает анимацию резки в реальном порядке обхода и выгружает G-code, DXF и SVG
(та же геометрия, что в `generate_panel.py`). Параметры сохраняются в браузере.

## Остаток: личные финансы
`ostatok/index.html` — учёт расходов в одну строку («350 кофе», «вчера 2500 такси», «+250000 зарплата»),
сколько можно потратить сегодня, чтобы уложиться в месяц, лимиты по категориям, регулярные платежи
с напоминанием о списании, выгрузка в CSV. Открытый как файл, хранит данные в браузере.
