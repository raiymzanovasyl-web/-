# Клоун: процедурная 3D-модель в Blender

Персонаж собран скриптами для Blender (модуль `bpy`, Blender 5.3) без ручной лепки.
Схема работы как у художников игровых персонажей: сначала анатомическое тело,
поверх него одежда и детали, затем низкополигональная версия с запечёнными текстурами и скелетом.

| Файл | Что внутри |
|---|---|
| `anatomy.py` | Анатомия: череп, лицевые массы, шея, грудная клетка с рёбрами, мышцы торса, спины, рук и ног, кисти с фалангами |
| `sdf.py` | Мини-набор для «цифровой лепки»: поле расстояний, плавное слияние и вычитание форм, marching cubes |
| `build.py` | Сцена: тело, грим (покраска по вершинам), глаза, зубы, нос, ногти, волосы, костюм, материалы |
| `render.py` | Свет, камеры, рендеры в Cycles |
| `export_game.py` | Игровая версия: LOD0, UV, запекание цвета и нормалей, скелет, экспорт `.glb` |
| `clown.blend` | Сцена высокой детализации |
| `game/clown.glb` | Игровая модель со скелетом, открывается в Unity, Unreal, Godot |
| `renders/` | Рендеры |

## Анатомия
- Рост 1,95 м, около 8 голов: вытянутый, истощённый силуэт.
- Голова: свод черепа, затылок, надбровная дуга, скулы и скуловые дуги, впалые щёки и виски,
  глазницы с тяжёлыми веками и мешками, носогубные складки, длинный острый подбородок, уши.
- Шея: грудино-ключично-сосцевидные мышцы, трапеция, кадык.
- Торс: грудная клетка с проступающими рёбрами, грудные, передние зубчатые, прямая и косые мышцы живота,
  широчайшие, лопатки, мышцы-выпрямители спины, гребни подвздошных костей, ягодичные.
- Руки: дельтовидные, бицепс, трицепс, плечелучевая и сгибатели, локтевой отросток;
  кисть с тенаром, костяшками и пятью пальцами по три фаланги, неестественно длинными.
- Ноги: прямая, латеральная и медиальная широкие мышцы бедра, бицепс бедра, приводящие,
  надколенник, икроножная с двумя головками, гребень большеберцовой кости, лодыжки, пятка, пальцы стопы.

## Пересобрать
```bash
pip install bpy scikit-image
python build.py                      # clown.blend
python render.py renders             # рендеры (полное качество, несколько минут на CPU)
python export_game.py                # game/clown.glb
```
`--quick` у `build.py` и `render.py` даёт черновое качество за секунды.

## Вторая версия: массивный клоун (`brute_anatomy.py`, `brute.py`)
По референсу заказчика: тяжёлая нахмуренная бровь, морщинистый лоб, нос-шар, оскал с крупными квадратными зубами,
брыли, пучки волос по бокам; тело громилы.

| Файл | Что внутри |
|---|---|
| `brute/clown_brute.glb`, `brute/clown_brute.fbx` | Игровая модель: 48 946 треугольников, 53 кости (имена как у Mixamo), запечённые текстуры |
| `brute/clown_brute.blend` | Высокополигональный скульпт (2 млн треугольников), игровая версия и скелет |
| `brute/textures/` | Карты цвета и нормалей (тело 2048 px, остальные 256–1024 px) |
| `brute/renders/` | Рендеры игровой модели, сетки, скульпта и позы |

Пересобрать: `python brute.py full` (около 20 минут на 4 ядрах CPU). Черновой просмотр: `python brute.py preview <папка> face hero`.
